# Demo 项目协作说明

## 任务目标

- 根据测试失败信息修复任务管理器的行为问题。
- 不要假设 README 已经指出了问题位置；先通过测试和代码阅读完成定位。
- 保持现有公开 API 和数据模型不变。
- 只修改实现代码；不要为了让测试通过而修改测试文件。

## 验证要求

- 修改完成后运行：`python -m pytest -q`
- 必须确认完整测试套件通过后，才能报告任务完成。
- 如果测试失败，先根据失败信息定位原因，再继续修改。

## 修改约束

- 优先采用最小、易读的修改。
- 保持 Python 3.12 类型标注和现有代码风格。
- 不新增第三方依赖。
- 不修改 `README.md` 和 `pyproject.toml`，除非任务明确要求。
